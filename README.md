# Sports Academy Training and Tournament Management System

A web-based application built using **Python (Flask)** and **SQLite** to manage sports academy training sessions and tournaments efficiently.

## 🚀 Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, Jinja2 Templates
